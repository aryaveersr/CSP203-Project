# CampusHub

A centralized platform for IIT Bhilai students to share course notes and discover campus events.

---

## Prerequisites

Make sure you have installed on your system:

- [Node.js](https://nodejs.org/) (v20 or higher recommended)
- [Git](https://git-scm.com/)

---

## How to Run the Project

Follow these steps to run the project locally:

### 1. Clone the repository

```sh
git clone https://github.com/aryaveersr/CSP203-Project.git
cd CSP203-Project
```

### 2. Install dependencies

```sh
npm install
```

### 3. Setup Environment Variables

Create a `.env` file in the root directory:

- On Linux / macOS:
  ```sh
  cp .env.example .env
  ```
- On Windows (PowerShell):
  ```powershell
  Copy-Item .env.example .env
  ```

_(Or simply create a file named `.env` and copy the contents of `.env.example` into it)._

### 4. Start the server

To run in development mode (with auto-reload on changes):

```sh
npm run dev
```

Or to run in standard mode:

```sh
npm start
```

### 5. Open in browser

Open your browser and navigate to:

```
http://localhost:3000
```
